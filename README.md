# SpeechFlow frontend (React + Vite)

VS Code: File > Open Folder > `speechflow-frontend`, then in the terminal:

    copy .env.example .env.local      (macOS/Linux: cp .env.example .env.local)
    npm install
    npm run dev

Open http://localhost:5173. Needs the backend (8080) and speech service (8000) running.
Build: npm run build
